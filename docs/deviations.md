| R4 | Baseline PPL expected in [6.0, 7.5] | Measured **30.33**; band corrected to [28, 33] | The plan's band was a misremembered literature number: ~6.5 is *word-level* perplexity; GPT-2 small's token-level WikiText perplexity is ~29-30 (GPT-2 paper: 29.41 on its WikiText-103 subset). CPU/MPS parity check confirmed the evaluator is correct (30.2002 vs 30.2012 on the same subset). The success criterion (SPECTRE ≤ 1.10 × baseline) is unchanged and now anchored to a verified baseline. |
| R5 | Batch 32, ≤10 epochs, 30-min hard stop, early stop 2 | Micro-batch 8 × grad-accum 4 (effective 32); 8 of 10 epochs completed across two 30-min budget windows (resume support added mid-run); no early stop triggered | A full 32-sequence batch through the SPECTRE FFT path spikes MPS memory past what a 48GB machine holds; 8×4 keeps optimizer math identical to batch 32. The 30-min budget cut the run mid-epoch-8; the val curve (230→48.6) was decelerating but not plateaued, so the remaining 2 epochs were finished in a follow-up run. |
| R6 | — | Verdict: **FAIL (ratio 1.620)** — test PPL 49.13 vs baseline 30.33 | Not a plan deviation per se: the plan defines an honest FAIL as a valid, reportable outcome. The gap is attributed to the frozen backbone having been pretrained with attention (never co-trained with SPECTRE) within a ~1-hour fine-tuning budget. Gate diagnostics moved in the paper's predicted direction (selectivity and input-discrimination both increased), so the mechanism itself behaves as advertised on real text. |
| R5b | — | Follow-up beyond the plan: co-training run (backbone unfrozen at 1e-5, 30x lower than SPECTRE's 3e-4; 10 epochs, 84.6 min, no early stop) — test PPL **47.36** (ratio 1.562) vs 49.13 frozen | Tests the R6 diagnosis directly.
